# Ember & Oak — Wood-Fired Kitchen

A warm, atmospheric landing page for a fictional wood-fired restaurant in Portland, Oregon. Dark, ember-toned design with a full interactive menu, opening hours, and a working reservation flow — all client-side.

## Features

- Sticky header with mobile hamburger menu
- Full-screen hero with layered overlay and dual CTAs
- Interactive menu with category tab filtering (Starters, Mains, Wood-Fired, Desserts, Drinks) rendered from a JS data object
- Reservation form with validation: name, 10-digit phone, date (no past dates, 60-day window), time slots, party size (1–12) — plus a confirmation summary state
- Opening-hours table that highlights today's row automatically
- Responsive layouts at 820px / 640px breakpoints

## Tech

HTML, CSS (custom properties, grid/flexbox), vanilla JavaScript. No frameworks, no build step — just open `index.html`. Hero photo via picsum.photos.
